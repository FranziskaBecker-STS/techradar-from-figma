# Design references

Read-only Figma MCP exports, screenshots, geometry and original-asset provenance for the Techradar app. The five content screenshots were supplied by the project owner.

Temporary Figma MCP asset/download URLs were removed from this repository export. The original runtime assets are already stored in public/assets/. New downloads require fresh URLs obtained via Figma MCP. The legacy scripts/download-assets.py checks for missing URLs before attempting a download.

The source workspace and its reference material were not modified during export.
